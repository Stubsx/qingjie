# 长截图存储与导出

长截图自动管理资源，不提供内存或缓存设置。采集和识别仍在 `ScrollCaptureWorker` 上执行。

- `ScrollImageStorage` 按物理内存的 1/128 设置分块驻留预算，范围为 32–128 MiB。系统出现内存压力时降至最多 8 MiB。这是分块缓存预算，不是整个应用的内存硬上限。
- 超过预算时将旧分块无损写入当前会话的私有临时目录，只保留最近的原图和小预览。预览随长图长度缩小并复用缓存，避免每次刷新都重新解码所有原图。
- 分块使用引用共享，固定区域、滚动条清理和弹性回滚的检查点可以继续读取落盘内容。持久化失败发生在追加提交前，保留此前已接受的画面。
- 采集预览保持直角，圆角与阴影只在完整 PNG 导出时统一添加。窗口本身的圆角可能已进入屏幕原图，拼接时从两帧重叠区接续并替换此前最多 128 行的底边，避免把窗口圆角和角落背景反复拼入正文；被替换的像素来自下一帧原始内容，不做涂抹补色。
- 超长图支持 PNG 和 PDF 文件交付。`VerticalStitcher.exportPNG` 在小画布上分段绘制，`QingJiePNG` 逐行编码；圆角、透明度、阴影沿用普通截图的几何规则。PNG 路径保留截图美化；普通尺寸支持 PNG/JPEG/PDF，超长图支持 PNG/PDF。
- 复制直接提交已编码的 PNG，历史记录通过文件复制保存，避免重新构建整张位图。剪贴板服务和接收应用的资源占用不受分块预算约束。
- 完成、取消或释放会话时清理临时文件。保存或复制失败保留结果以供重试。目录锁保护活跃会话，并在下一次创建缓存时回收异常退出的残留目录。
- 原来的 3200 万像素、4 万像素高度和 1000 帧默认阈值已移除。仍校验格式尺寸和整数范围；磁盘空间不足时暂停并保留已捕获内容。

验证：`swift test -c release` 覆盖强制落盘后的拼接、回滚、滚动条清理、预览、分段美化、越过旧阈值、写入失败和文件生命周期。签名构建的 `--smoke-test` 覆盖文件交付、剪贴板、历史记录与取消/重试。可运行应用必须通过 `scripts/build.sh` 构建。

## PDF 自动分页

- 用系统 CoreGraphics 直接写入 A4 PDF，不随应用分发解释器、浏览器或 PDF 引擎。输出为图片型 PDF，不增加 OCR 文字层或原网页链接。
- 保存面板先选择格式，再开始导出。长截图的 PDF 直接读取分块，不先生成完整 PNG 或位图；普通截图与标注图片复用同一分页器。
- 页内保留原始像素分辨率，按宽度等比放置，白底、24 pt 左右页边距和页码。每次最多绘制约 8 MiB 的图像条带。
- 在预计页底之前的小范围内分析水平图像变化，优先选择空白行；没有可靠空白时按页高切分。所有源行只出现一次，末页保留剩余内容。此启发式不保证复杂表格、照片或图表能够完整落在同一页。
- PDF 写入同目录临时文件，完整关闭并回读页数后整体替换目标。取消或写入失败时保留已有目标和本次捕获内容，以便重试。
- 最近记录保留完整 PDF，使用系统能力生成首页缩略图并显示页数，点击交由系统默认 PDF 阅读器打开。PDF 和 PNG 共同遵循最多 30 项的保留策略。

`PDFExportTests` 覆盖分页边界、末页、磁盘分块、取消清理、文档回读与超长导出。应用自检覆盖普通图片和滚动长图的 PDF 保存、取消、重试及历史记录。设置 `QINGJIE_PDF_QA_DIR` 运行签名构建的 `--smoke-test` 可以输出纯演示内容的 PDF 和原图，供渲染检查。
