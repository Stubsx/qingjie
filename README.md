# 轻截 · 原生 macOS 截图与标注

面向日常截图标注的小工具，以 iShot 的常用工作流为参考。使用 Swift、AppKit、SwiftUI、ScreenCaptureKit 和 Vision；无第三方依赖。除「自动检查更新」每天匿名读取一次版本信息（可在设置关闭）外，不连接任何外部服务；截图与识别全部在本机完成，不上传数据。

## 直接运行

**下载**：在 [Releases](https://github.com/Stubsx/qingjie/releases) 下载 `qingjie-macOS-arm64.zip`，解压后把 **轻截** 拖进「应用程序」。当前构建适用于 **Apple Silicon Mac，macOS 14 或更新版本**。

应用使用本机固定证书签名（未做 Apple 公证），首次打开时 macOS 可能提示"无法验证开发者"：**右键（或按住 Control）点击应用图标 → 打开**，在弹窗中确认即可。只需一次，之后正常使用；应用内自动更新下载的包不受此限制。

从访达「应用程序」打开 **轻截**（`/Applications/轻截.app`）。开发更新通过 `./scripts/build.sh` 构建、退出应用后用 `./scripts/install.sh` 安装；保持同一个安装位置。

第一次截屏前，在 **系统设置 → 隐私与安全性 → 屏幕与系统音频录制**（部分版本称「屏幕录制」）中打开「轻截」，然后退出并重新打开应用。可从工作台左下角进入设置。若权限列表没有轻截，会显示可拖拽的授权浮条：把图标/名称拖入系统列表，再按系统提示开启开关。拖拽载荷始终指向 `/Applications/轻截.app`；macOS 是否接受添加由系统决定。

不授权也能点击 **体验标注**，体验相同的框选和屏幕内标注流程；也可打开已有图片使用独立编辑器。

0.5.3 起使用固定本机签名证书和 Bundle ID，后续构建不再使用随代码变化的临时签名身份。旧版迁移到固定身份时可能需要再授权一次。证书保管、构建校验和未来正式发布迁移规则见 [应用身份说明](docs/APP_IDENTITY.md)。

屏幕内标注使用数字键 `1–7`：选择、矩形、椭圆、箭头、画笔、文字、马赛克。输入文字时 Enter 换行，`⌘Enter` 或「添加文字」确认；Esc 取消当前文字。独立图片编辑器还支持 `8` 裁剪。`⌘Z` 撤销，`⇧⌘Z` 重做。框选或绘制矩形/椭圆时，按住 Shift 可约束为正方形/正圆。

窗口识别结合 macOS 窗口边界、前后顺序与本机图像识别，无需额外权限。启动截图时冻结画面与候选窗口，悬停即高亮，单击选中；鼠标轻微抖动仍按单击处理，拖动则自由框选。窗口标题栏包含在选区内，外部阴影不包含。重叠时按鼠标所在位置选择最前面的窗口；截取的是当前屏幕可见画面，被遮挡的内容不会补全。跨屏或超出屏幕的窗口仅截取当前显示器内的部分；桌面、菜单栏、Dock 和轻截自身界面不参与自动选窗。「重新框选」继续使用同一冻结画面和窗口边界。

网页弹窗或应用内浮动面板没有独立系统窗口编号时，会在冻结截图中识别清晰、闭合的矩形表面。鼠标位于面板内优先选面板，移到外围优先选择可识别的网页内容，否则回退到应用窗口；按住 **Option（⌥）** 可临时选整个应用窗口。识别排除小按钮、输入框、细边线、低对比区域及被前方窗口遮挡的候选区域；面板内部的卡片不会覆盖外层弹窗。识别在捕获时后台执行一次，鼠标移动只查找候选范围。

Chrome、Chromium、Edge 和 Brave 的常规横向工具栏增加「网页内容」吸附层：根据地址输入框的形状、留白和下方横向分隔线确定页面起点，页面选区保持窗口全宽和底边，包含网页自己的侧栏与导航。鼠标移到标签栏或地址栏时选整窗；Option 可临时绕过弹窗和网页内容两层。不会使用固定像素高度裁掉顶部。有书签栏时优先采用其下方分隔线；同色且没有分隔线时按检测到的地址框和留白估算边界，可在选中后拖四角微调。工具栏被遮挡、顶部/两侧超出屏幕，或无法辨认地址框时回退。其他浏览器和特殊垂直标签栏布局暂不做内容区推断。

这是一种保守的图像识别：透明、渐变、复杂背景、边界不完整或与页面接近的面板可能回退到应用窗口；仍可拖动自由框选，单击选中后也可拖四角调整。不会读取网页 DOM、连接网站、上传图片或请求辅助功能权限。

区域截图、全屏截图和长截图均可选择「完成复制」或「另存为」，完成后关闭选区和工具栏，不弹工作台或编辑窗口，并在本机「最近截图」中保留最终成品。取消或失败的操作不生成历史，连续相同成品沿用合并规则，最多保留最近 30 张。另存为支持 PNG（默认无损）和 JPEG，可选择任意可写文件夹；保存成功后记住位置。取消或保存失败保留本次图片，长截图会暂停，可重试保存、复制或继续采集。另存为不会覆盖剪贴板。全屏截图现在直接选中整个屏幕并显示同一工具栏，按 Enter 即可复制。只有最终图片会导出，遮罩、边框、工具栏和文字输入框不会包含在图片中。

自动识别窗口或自由框选后，可以拖动整条边线或四个白色控制点扩大、缩小范围。左右边线只调整宽度，上下边线只调整高度；鼠标靠近边线显示相应的缩放光标，四角继续优先同时调整宽高。边线附近有 6 pt 的响应范围，选区内部继续用于标注；按下时保留鼠标相对边框的偏差，避免点击跳动。单边拖动即使按住 Shift 也只调整对应轴；四角仍可用 Shift 约束正方形。标注保持在原来的屏幕位置，暂时位于选区外的标注不会被删除，扩大选区可重新显示；一次拖动对应一次撤销。后续复制、另存为和长截图均使用调整后的范围。

不必切换选择工具：鼠标碰到线条、箭头、画笔、文字或马赛克时会显示手形，按住即可拖动。矩形/椭圆只在边线上响应，内部空白仍可画新标注；点击边线后出现四个控制点，可直接缩放。马赛克也可整体移动和调整大小。

选区工具栏的全部操作使用纯图标：标注、撤销/重做、重新框选、长截图、取消、另存为、完成复制和文字确认，共用 20 × 20 pt 矢量网格、1.7 pt 圆角线条和 36 × 36 pt 正方形点击区域。功能名称与快捷键保留在悬停提示和辅助功能标签中。五个截图操作集中排列在第一行右侧，第二行放颜色与样式，底部显示提示和像素尺寸；整体高度从 180 pt 收紧到 132 pt。马赛克下拉移入样式行，切换工具不会挤动第一排图标。完成复制用绿色背景突出，尺寸与其他按钮一致。长截图浮窗的演示滚动、暂停/继续、取消、另存为和复制也使用同一套图标与按钮。

长截图时，内容区保持明亮，其他区域变灰，预览优先放在左右空余位置。预览自动跟随新增内容到末端，鼠标移入预览可滚动检查之前的画面，下方仅显示当前宽高像素，保留暂停、另存为、完成复制和关闭。只有需要处理的捕获异常才显示提示；全屏选区没有外部空间时，预览浮在屏幕内，浮窗和灰色遮罩均从采样中排除。

点击马赛克工具后，其右侧会出现样式下拉框。每次新截图默认 **高斯模糊**；增大强度会加重毛玻璃效果。**像素块**保留传统块状效果，**纯色遮挡**用当前选中的颜色完全覆盖，选择黑色即可黑条遮挡。

颜色栏的 **吸管** 可直接吸取屏幕颜色。截图遮罩会在取色期间暂时隐藏，避免采到变暗的颜色；单击取色或按 Esc 取消后回到原选区，已有标注保留。当前色块与 `#RRGGBB` 同步显示取到的颜色。样式和颜色选择应用于后续绘制的标注，各标注保留自己的样式并支持撤销重做。文字工具使用固定的 **T** 图标。

独立图片编辑器保留保存、贴图和 OCR 功能；截图及编辑器导出历史统一存储在：

```text
~/Library/Application Support/QingJie/History/
```

## 截图美化

点击工作台侧栏的 **设置 → 截图美化**，可独立开启 **圆角矩形** 和 **窗口阴影**，右侧实时预览效果。可调圆角 **0–64 pt**、阴影大小（模糊半径）**0–48 pt**、向下偏移 **0–32 pt**、阴影浓度 **0–100%**；滑块旁显示数值。圆角默认采用 macOS 风格的 **R12 pt**，随屏幕像素密度换算，例如 2× Retina 默认对应 24 px，并非动态读取系统窗口圆角。阴影在图像外围增加透明留白，不缩放截图内容。

区域、全屏和长截图的 PNG 保存与剪贴板复制共用同一美化效果；JPEG 保持原始矩形和尺寸。圆角以透明像素呈现，预览中的棋盘格不会写入图片。开启阴影会增加输出图片的宽高。截图选区仍可拖动边线或四角调整，标注坐标与长截图拼接使用原始图像，美化仅在最终输出时添加一次。

美化区的 **恢复默认** 将四个参数恢复为 **12 pt / 12 pt / 6 pt / 24%**，保留圆角与阴影开关状态；快捷键区有独立的恢复默认。参数为 0 时可得到直角或无模糊的硬阴影；浓度为 0 时不添加阴影留白。设置自动保存，从下一次截图生效。首次升级两项均默认关闭；打开已有图片的独立编辑器不应用这些截图设置。

## 自定义截图快捷键

点击工作台侧栏的 **设置**，在右侧页面向下滚动到 **截图快捷键** 分区。截图美化与快捷键按大标题平铺，无需切换分类。菜单栏的 **设置…** 和 **⌘,** 也会切换到工作台的同一设置页面。

- 点击区域截图或全屏截图右侧的按键，直接按下新的组合，成功后立即生效并自动保存。
- 按住修饰键时，录入框会显示已收到的组合，例如「⌃⌘ + …」。也可点右侧 **选择**，分别勾选 Control、Command 等修饰键、在「主键」中选择 A，再点 **保存**；这些控件直接在当前页面展开。
- 至少包含 **⌘、⌥、⌃** 中的一个，可再搭配 Shift；支持字母、数字、方向键和功能键等。只按 Shift 或普通字母不会被保存。
- **Esc** 取消录入；不带修饰键的 **Delete** 或右侧清除按钮可停用该项快捷键。截图按钮和菜单仍然可用。
- **恢复默认** 将两项改回 ⌥⇧A、⌥⇧F。长截图统一从框选后的工具栏进入，不单独设置快捷键。
- 检测应用内重复、常用编辑命令及 macOS 已启用的系统快捷键。其他应用占用导致注册失败时，不保存冲突组合并尝试恢复原绑定；恢复失败会明确提示，可逐项更换。

录入期间会暂停轻截的截图快捷键，避免误触；取消、完成、操作美化参数或切换侧栏页面、关闭窗口或切换到其他窗口时恢复。工作台和菜单同步显示当前设置；无需辅助功能或输入监控权限。升级至 0.6.2 会移除旧长截图绑定，保留已自定义或停用的区域、全屏快捷键。

如果一直等待录入，可点 **选择** 来设置组合。鼠标选择同样执行重复组合、系统保留键及注册冲突校验，失败时保留原设置。它能绕开组合按键未送达录入框的问题；其他应用若拦截实际按键，仍需调整冲突组合。轻截不会修改其他应用或系统的快捷键设置。

点击 **检测快捷键** 后有 30 秒时间切换到其他应用并按键，检测期间不截图。检测结果区分系统全局事件与仅应用内按键，并显示录屏权限。注册失败会显示系统状态码。注册成功并不能排除其他软件的键盘拦截，需以真实按键检测为准。

下面的操作说明使用默认组合，自定义后使用对应的新快捷键即可。

## 滚动长截图

1. 打开想截取的网页、文档或聊天记录，停在起始位置。
2. 按普通区域截图快捷键（默认 **⌥⇧A**），框选要截取的页面范围，再点击选区下方工具栏的 **长截图**。直接沿用当前范围，无需再框一次。可包含顶栏、侧栏及目录，**无需再次指定内容区**。将鼠标停在想截取的正文上，开始向下滚动；应用会通过连续画面的运动自动锁定滚动面板。
3. 用鼠标滚轮或触控板**缓慢自然向下滚动，无需每次停顿**。每次采样只要能可靠匹配重叠就追加新内容，浮窗显示实时预览和像素尺寸。不要快速甩动、拖滚动条跳过大段内容。
4. 到达末尾后，点击 **完成复制** 粘贴使用，或点击 **另存为** 选择文件夹和格式保存。

进入长截图前若已绘制标注，请先撤销标注；工具栏会暂时禁用长截图，避免切换时丢失标注。选择了标注工具但尚未绘制时，可直接开始长截图。

浮窗可以拖动，截图期间不会出现在成品中。「暂停」停止采集；恢复前应回到最后捕获的位置。「取消」丢弃本次长截图，未完成的画面不写入最近记录。需要进一步编辑时，可从「最近截图」打开已完成的成品。

底部回弹和短暂上滑会自动处理：保留已捕获位置，不要求用户回到末端；回到新内容时自动接续。回弹露出的空白会等待稳定；已短暂累计的纯空白尾部在弹回时可撤回。真实稳定的页尾留白仍可保留。已识别为回看期间，无法与最远位置重叠的画面不会触发回滚警告；完成时可直接输出已经捕获的内容。真正断层或无可靠匹配持续出现时，仍会提示放慢或回滚，程序不会强行猜测。完成时最多等待约 1.5 秒让末帧稳定。

**自动图像识别**：先比较连续画面，再对横向图像块做垂直位移匹配和一致性投票，区分正文的整体滚动与侧栏动画、数字刷新等独立变化。沿同一位移的像素分布识别面板边界，并对整个候选内容区复核像素重叠后才拼接；不只凭“哪里变了”决定范围。

页面上有多个独立滚动面板时，优先选择鼠标所在的、具有可靠运动证据的面板。没有明确目标且多个面板证据相当时不强行猜测。鼠标位置只用于选择目标，不需要辅助功能或输入监控权限。识别和拼接均在本机完成，无需联网、下载模型或上传截图。

两侧固定区域或独立变化的侧栏自动裁掉，内容区宽度内的固定顶栏和底栏保留一次。绿色边框显示识别结果，第一次成功拼接后锁定范围。自动识别沿背景分界或分隔线尽量保留正文留白；没有明确分界时可能裁掉部分静止边距。

多列表格会把具有相同滚动位移的各列作为同一个内容区：列间空白、重复的日期和类型值不会单独当成固定侧栏。选区边缘只有很窄的异常区域时保留原宽度，避免切掉列尾。1–8 像素的固定分隔线或浅阴影在确认位移后单独识别，底部边线随最后一帧保留，不再重复夹入接缝。

动态收缩顶栏、遮挡正文的悬浮窗、大片空白、周期性重复列表及横向移动仍可能无法可靠匹配。截图期间请保持窗口位置、大小和显示器缩放不变。

当前版本由用户滚动页面，自动采集并拼接，不会自动操纵其他应用滚动。仅需屏幕录制权限，不需要辅助功能或输入监控权限。一次只支持一个显示器内的单个纵向滚动区域，最多 40,000 像素高、3,200 万像素或 1,000 段，任一上限到达后停止追加，可保存现有部分。

**无需授权的演示**：进入工作台的「使用指南」，点击「体验长截图（无需屏幕权限）」，框选示例后点击工具栏 **长截图**。示例包含固定顶栏、持续刷新背景的左右侧栏和可滚动的中文文档。每点一次「示例向下滚动一段」便模拟一次滚动；演示与真实截屏共用选区工具栏、区域识别、采样拼接和完成逻辑。

## 开发与构建

需要 Xcode 15 或更新版本（包含 Swift 5.9+）。本机使用 Xcode 26.6 / Swift 6.3 编译通过。

```bash
# 生成 dist/轻截.app，使用已固定的本机证书签名并校验身份
./scripts/build.sh

# 退出轻截后安装到固定位置
./scripts/install.sh

# 运行单元测试、身份连续性与图像处理 / OCR 集成检查
./scripts/verify.sh

# 打开工作台
open /Applications/轻截.app

# 生成经过身份验证的本机使用压缩包
python3 scripts/app_identity.py package

# 生成更新源 dist/latest.json（--package-url 指向已上传的压缩包）
python3 scripts/app_identity.py feed --package-url https://example.com/qingjie-macOS-arm64.zip --notes "更新说明"

# 或用 gh CLI 上传压缩包到 GitHub Release 并生成更新源（自动推导下载地址）
python3 scripts/app_identity.py feed --github-repo owner/repo --notes "更新说明"

# 生成后直接写入 gist（需要 QINGJIE_GIST_TOKEN 环境变量），一条命令完成发版
python3 scripts/app_identity.py publish --github-repo owner/repo
```

也可以用 Xcode 打开 `Package.swift` 编辑代码。需要屏幕权限的实机测试使用固定安装的 `.app`；不要直接运行 Xcode/Swift 的未签名二进制申请权限，以免系统将权限归到宿主终端。此工作区已固定证书指纹；换机器开发需恢复原 Signing 目录，脚本不会静默更换证书。

